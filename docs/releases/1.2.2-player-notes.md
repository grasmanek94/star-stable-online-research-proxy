# Star Stable Online FPS Fixer 1.2.2

An unofficial Windows plugin that can improve FPS by hiding other players' characters, horses and pets, with optional presets for NPCs, decorative effects and other visuals.

**Account ban risk:** Installing and using this plugin likely violates [Star Stable's Terms of Service](https://help.starstable.com/hc/en-us/articles/4404692524946-Your-License-to-use-the-game-service) and **could get your account banned**. Star Stable says it [takes action against unauthorized modifications](https://www.starstable.com/en/article/player-safety). Using the ReShade build does not imply approval from Star Stable.

## Download and install

For the simplest setup, choose **SSO-Visibility-Proxy-1.2.2-PROXY-win64.zip**. Close the game, extract the ZIP and place `opengl32.dll` and `SSOVisibility.ini` beside `SSOClient.exe` in the game's `client` folder. Launch normally, enter the world and press **F5**.

Already using ReShade? Keep its `opengl32.dll` and use the **RESHADE** download with 64-bit ReShade's full addon support. ASI and PLUGIN builds need a compatible loader. Install only one build.

- **F5:** enable hiding; preset 8 is the default (other players, horses and pets).
- **F6:** disable hiding and show things again.
- **Ctrl + Numpad 0:** all supported hiding filters.
- **Ctrl + Numpad 1–9:** presets, from more hiding to less hiding. Preset 9 hides other players and horses only.
- **F7:** reload settings saved in the INI. Keep NumLock on for presets.

**[Read the simple guide and full preset list](https://github.com/grasmanek94/star-stable-online-quality-of-life-improver#readme).** Aggressive presets can hide useful race/quest visuals. Preserve your customized INI when updating.

Each player ZIP contains **only the plugin file and INI**. The all-loaders ZIP contains four alternatives; pick one folder. The source ZIP is for building the plugin yourself. Research, AI notes, diagnostics and symbols are excluded from player downloads.
