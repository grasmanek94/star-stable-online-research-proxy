# Star Stable Online FPS Fixer 1.3.0

An unofficial Windows plugin that can improve FPS by hiding other players' characters, horses and pets, with optional presets for NPCs, decorative effects and other visuals.

**Account ban risk:** Installing and using this plugin likely violates [Star Stable's Terms of Service](https://help.starstable.com/hc/en-us/articles/4404692524946-Your-License-to-use-the-game-service) and **could get your account banned**. Star Stable says it [takes action against accounts using unauthorized modifications](https://www.starstable.com/en/article/player-safety). Using the ReShade build does not imply approval from Star Stable.

## Download and install

For the simplest setup, download **SSO-Visibility-Proxy-1.3.0-PROXY-win64.zip**. Close the game, extract the ZIP and put `opengl32.dll` and `SSOVisibility.ini` beside `SSOClient.exe` in the game's `client` folder. Launch normally, enter the world and press **F5**.

Already using ReShade? Keep its `opengl32.dll` and use the **RESHADE** download with 64-bit ReShade's full addon support. ASI and PLUGIN builds need a compatible loader. Install only one build. Preserve your customized INI when updating.

## Keys

- **F5:** enable hiding; preset **8** is the default (other players' characters, horses and pets).
- **F6:** disable hiding and show things again.
- **Ctrl + Numpad 0:** all supported hiding filters.
- **Ctrl + Numpad 1–9:** presets, from more hiding to less hiding. Preset **9** hides other players' characters and horses only.
- **F7:** reload settings saved in the INI. Keep NumLock on for presets.

Presets0–4 are aggressive and can hide useful race/quest visuals. Read the guides above for the complete preset list and settings.
